### ① 为什么 TUN 模式开了就断网？

TUN 模式本质是创建一个虚拟网卡，劫持**所有**系统流量走代理。你的 Clash 配置里：
```
auto-route: true        → 修改系统默认路由表
dns-hijack: any:53      → 劫持 DNS 解析
stack: gvisor            → 用户态协议栈
```

问题出在 **路由循环**：TUN 网卡劫持流量 → 发给 mihomo 内核 → mihomo 再通过 TUN 网卡出去 → 死循环。而且 `gvisor` 用户态协议栈在 Linux 上和 iptables/nftables 配合不稳定，经常丢路由。

**结论：TUN 就别开了。** 你现在用的 `enable_system_proxy: true`（HTTP 代理 7897 端口）完全够用，不需要 TUN。
