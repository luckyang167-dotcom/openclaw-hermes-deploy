## 项目概述

**LEAP_ROS** 是一个基于 **ESP32-S3** + **micro-ROS** + **ROS2 Humble** 的差速小车开源项目，由"出云科技"提供。

### 硬件组成
| 部件 | 说明 |
|------|------|
| 主控 | ESP32-S3（双核、Wi-Fi/蓝牙、4MB Flash） |
| 电机 | TT 直流减速电机，9V/150RPM，减速比 1:90 |
| 激光雷达 | Camsense D2 三角测距雷达 |
| IMU | 六轴姿态传感器（板载） |
| 供电 | 8.4V 锂电池 |

### 软件架构
```
应用层：  RViz2 / SLAM / Nav2 / 键盘遥控
  ↑
ROS2 通信层：Micro-ROS Agent（UDP 8888）→ /cmd_vel, /odom, /imu, /scan
  ↑
固件层：  ESP32 micro-ROS 固件
  ↑
硬件层：  电机/编码器/IMU/雷达/电池
```

### 复现步骤

1. **导入虚拟机**：VMware 打开预配置的 Ubuntu 22.04 + ROS2 Humble 镜像，网络设为桥接模式
2. **配网**：小车上电后连接其热点 `Maturo_xxx` → 浏览器配置 Wi-Fi → 填写 micro-ROS Agent IP（虚拟机 IP）和端口 8888
3. **启动 micro-ROS Agent**：
   ```bash
   sudo docker run -it --rm --privileged --net=host \
     microros/micro-ros-agent:$ROS_DISTRO udp4 --port 8888 -v6
   ```
4. **验证通信**：`ros2 topic list` 应看到 `/odom`, `/imu`, `/scan`, `/battery_state`
5. **SLAM 建图**：
   - 启动底盘 TF：`ros2 launch xuegecar_bringup xuegecar_bringup.launch.py`
   - Gmapping：`ros2 launch slam_gmapping slam_gmapping.launch.py`
   - 或 Cartography：`ros2 launch xuegecar_cartographer cartographer.launch.py`
   - 保存地图：`ros2 run nav2_map_server map_saver_cli -f room`
6. **Nav2 导航**：
   ```bash
   ros2 launch xuegecar_navigation2 navigation2_rviz.launch.py map:=/path/to/map.yaml
   ```
